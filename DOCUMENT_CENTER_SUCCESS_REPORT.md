2. System shows 4 required documents:
   - ID Verification
   - Social Security Card
   - Proof of Address
   - Academic Transcript
3. Student uploads all 4 documents
4. Documents status = "pending"
5. Admin reviews in document center
6. Admin approves all documents
7. Student can proceed with enrollment

## 📞 SUPPORT & MAINTENANCE

### Database Maintenance:

```sql
-- Check document requirements
SELECT role, COUNT(*) as total,
       COUNT(*) FILTER (WHERE is_required = true) as required
FROM document_requirements
GROUP BY role;

-- Check pending documents
SELECT COUNT(*) FROM documents WHERE status = 'pending';

-- Check expiring documents (next 30 days)
SELECT COUNT(*) FROM documents
WHERE expiration_date BETWEEN NOW() AND NOW() + INTERVAL '30 days';

-- Check audit log size
SELECT COUNT(*) FROM document_audit_log;
```

### Adding New Document Types:

```sql
INSERT INTO document_requirements
  (role, document_type, is_required, description, instructions, accepted_formats, max_file_size)
VALUES
  ('student', 'vaccination_record', true, 'COVID-19 Vaccination Record',
   'Upload proof of COVID-19 vaccination', ARRAY['pdf', 'jpg', 'png'], 5242880);
```

### Updating Requirements:

```sql
-- Make a document optional
UPDATE document_requirements
SET is_required = false
WHERE role = 'student' AND document_type = 'drug_test_results';

-- Change file size limit
UPDATE document_requirements
SET max_file_size = 20971520  -- 20MB
WHERE document_type = 'facility_photos';
```
